Static Portfolio Website
A responsive, modern portfolio website built with HTML, CSS, and vanilla JavaScript to showcase web development skills.

Features
Responsive design that works on mobile, tablet, and desktop
Modern minimalist aesthetic with a professional color scheme
Smooth scrolling and navigation
Interactive project cards with hover effects
Contact form with client-side validation
Animated UI elements
File Structure
index.html - The main HTML file containing the structure of the website
styles.css - All styling for the website with responsive design
script.js - JavaScript for interactive features like form validation and navbar behavior
How to Use
Customize Content:

Update personal information in the HTML file
Replace placeholder images with your own
Update project details and links
Set your own social media links
Styling Changes:

The primary color scheme is defined at the top of styles.css
You can modify colors, fonts, and other design elements there
Form Functionality:

Currently, the contact form is for demonstration only
To make it functional, you would need to add server-side processing
Customization Guide
Personal Information
Edit the following sections in index.html:

Name in the navbar and landing section
Tagline on landing page
About me text
Experience and education details
Skills list
Contact information
Resume download link
Images
Replace these images with your own:

Background image in landing section
Profile photo in about section
Project thumbnails
Projects
For each project in the projects section:

Update project title, description, and technologies
Replace project image
Update links to live demo and GitHub repository
Social Media
Update the href attributes on social media links in the contact section.
